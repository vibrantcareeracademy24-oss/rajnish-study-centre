RAJNISH STUDY CENTRE – Free Online Worksheet Demo

1. Create a GitHub repository and upload all files.
2. GitHub → Settings → Pages → Deploy from branch → main → /(root).
3. Create a Supabase project on its Free plan.
4. Supabase → SQL Editor → run supabase.sql.
5. Copy Project URL and anon/public key into config.js, then upload it to GitHub.
6. Never put a Supabase service_role/secret key in this project.

This demo allows students to submit results anonymously. A protected teacher dashboard should be added separately so student results are not publicly readable.
